# Wand for Mac

Releases of the Wand macOS app (Apple Silicon, macOS 13+). Source is private; this repository holds the signed, notarized releases.

Install: `curl -fsSL https://wandapp.github.io/install.sh | sh`, or download `Wand-macOS-arm64.dmg` from the latest release.

More at https://wandapp.github.io
